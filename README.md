# FFT Innate Skills

A Reloaded-II mod for **Final Fantasy Tactics: The Ivalice Chronicles** that grants abilities innately to your characters, freeing up support slots. Configured for **Poach** and **Tame** by default.

### Features
* **Innate Poach & Tame:** Active automatically on player generics and story units (Ramza, Agrias, Orlandeau, etc.).
* **Custom Skills:** Add any extra ability IDs (hex or decimal) through the Reloaded-II mod config.
* **Non-Destructive:** Scans each job's 4 innate slots and only fills empty ones.

### Requirements
* [Reloaded-II](https://github.com/Reloaded-Project/Reloaded-II)
* [FFTIVC Mod Loader (v1.7.3+)](https://github.com/Nenkai/fftivc.utility.modloader/releases)

### Installation
1. Download `FFTInnateSkills.zip` from [Releases](../../releases).
2. Extract the folder into `Reloaded-II/Mods/`.
3. Enable in Reloaded-II and play!
